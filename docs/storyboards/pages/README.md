# おぐらじあ 第1部ネーム正本（ページ別）

第1部「ひなげし到着〜命名」のネーム正本。ページごとに `pXX.md` を1ファイルとして持つ。各ファイルは同じ3セクション構成にする。

1. **要件** — このページで何を伝えるか（役割、開始/終了状態、知識・関係の変化、ページをめくる理由、見せないもの、完成条件）
2. **ネーム** — 要件を実現する現在有効なコマ割り・演技・台詞の設計。過去に不採用となった版の履歴も含む（不採用でも記録は残す）
3. **レビュー結果** — 編集者ゲート・ネームレビュー・各工程（layout_lock/blocking/acting/rough）の絵レビュー判定を時系列で記録

このファイル分割より前の正本は `docs/storyboards/ogurasia-page01-10-name-specifications.md` に1ファイルとして存在していたが、文章とYAML相当の構造化データが同じページについて何箇所にも重複し、現行状態が読み取りにくかったため分割した（2026-09-09）。旧ファイルは分割済みへのポインタだけを残す。

吹き出し形状・外接比・背景画材・パネル遷移ゲートなど**全ページ共通の制作ルールは `ogurasia-page` / `ogurasia-name-review` / `ogurasia-art-review` の各スキルが正本**。このファイルには、スキル側に置くほど汎用ではないが特定の1ページにも属さない、おぐらじあ固有の作風メモだけを残す。

## おぐらじあ固有の作風メモ（全ページ共通・ページ非依存）

- 縦長9:16。上から下、各段は右から左、段が変わると上から下という日本語漫画の読む順を守る。英訳でもページを左右反転しない。日本語版の台詞は縦書き、英語版は横書き。
- 1ページ3〜6コマ（p10のみ7コマ）。均等な縦積み・4コマ風グリッド・同じ高さの横長コマの連続は禁止。最低1つは縦長コマを入れる。大きな主役コマ、小さな観察コマ、余韻コマを混在させる。
- コマの区切りは長方形だけにせず、斜め境界、辺の省略、ページ端まで開く枠、人物が枠をまたぐ構図を使う。横並びのコマ間は狭く、段と段の間は横の間隔の2〜3倍を目安に広く取る。
- 白・黒・中間グレーの3濃度。人物の主線は背景線より強くする。線は完全に均一・閉じたベクター輪郭にせず、Gペンの入りと抜き、線幅の揺れ、局所的な墨だまり、意図的な未接続を残す。
- 完成線の外側に、動き・髪・手元・背景の一部へ限って薄く粗い下書き鉛筆線を残してよい。服のシワ・背景の細部・肌の質感の説明には使わない。
- 少年は正本シートの形状固定（目を覆う一続きの髪、後ろの小さな結び、普通のシャツ、短いズボン、簡略な靴）。ジアは正本シートの形状固定（褐色肌、大きく横へ流れる黒髪、白い曲線3本、少年から借りた開いたフード付き上着とズボン、コート内側は裸）。どちらも一般的な体型・髪型へ正規化しない。
- 背景は墨筆で描いたような輪郭・にじみ・薄い面（`INK_BRUSH`）または飛ばしたインクのドリップ画報（`DRIP_GAHO`）のみ。写実的な建築・海・人体、コンセプトアート、均一な遠近線・波紋・窓・石のテクスチャは描かない。
- 長距離移動・時間経過・室内外の切り替え・主体交代の直後は、人物なしの新シーン背景コマ、墨模様・黒ベタ・トーン、背景に溶ける独白、コマまたぎの2頭身デフォルメのいずれかで転換を渡す。全コマにキャラクターを詰めない。
- 同じ構図・距離・向き・ポーズを連続させない。カメラ距離、身体の向き、重心、手足の折れ方、画面内位置のうち最低2つを変える。
- 竿は折りたたみ式。室内・通路・移動中は収納、釣り場では展開し、状態変化を前後のコマから読めるようにする。
- 生成画像に日本語を描かせない。台詞・ナレーションは文字レイヤーで後入れする。
- 参照軸は二つに分け、混ぜて一つの作風にしない。物語の寓話的な不条理・夢の飛躍・かわいさの裏の教訓は『ちいかわ』を手本にする（筋・キャラクター・台詞回しは模倣しない）。絵とネームの人間らしさ（荒い線、描き込み差、大胆な省略）は『HUNTER×HUNTER』を手本にする（既存のコマ・構図は再現しない）。

## 人物演技と吹き出しの必須条件（全ページ共通）

- ラフでも人物を直立の説明人形にしない。各コマに、手・足・肩・首・視線のうち最低2つの方向変化を入れる。
- 表情は目だけで描かない。髪で目が隠れる少年は口元・首の角度・肩の上がり・身体の引きで反応を表現する。ジアは目・口元・髪の流れ・片手の仕草で描き分ける。
- 台詞があるコマには空白の吹き出しを必ず置く。少年は `BOY_CLOUD_DOUBLE_ROUND`（二つの不均等な丸み＋短いくびれ）、ジアは `JIA_OCTAGONAL_LONG_CARDINAL`（上下左右の辺が長く四隅の斜辺が短い八角形）に固定する。単なる円・楕円・丸角長方形は禁止。
- 長い台詞は一つの巨大な吹き出しに詰めず、沈黙・視線・反応のコマを間に挟んで複数の吹き出しへ分配する。
- 吹き出しがないコマにも視線の目的を一つ置く。
