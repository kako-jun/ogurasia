# p06「黒い波」

## 要件

- role: 水面の異変を面積の増加で見せる
- previous_page: p05
- next_page: p07
- start_state: 少年は釣りを始める直前で、水面は静かである
- end_state: 少年は巨大な黒い塊をクジラだと認識する
- knowledge_delta: 黒い塊が海から浜へ現れた
- relationship_delta: 少年と未知の存在が同じ画面に入る
- page_turn_reason: 黒い塊が別の姿へ変化する
- must_not_explain: 写実的なクジラのanatomy、目、潮吹き、怪物らしい演出
- panel_count: 6
- 完成条件: 黒い面積が増えるだけで、読者が「何か大きなものが来た」と理解できる

## ネーム

役割：水面の黒い面積が増えることで異変を読ませる。静けさから黒い塊への面積変化を主役にする。

1. **上段右・縦長コマ**。上辺・右辺を開放し、左辺・下辺を残す。少年が竿とバケツを準備する。背景はほぼ白、水面を一本だけ。
   - purpose: 釣りの準備を完了させる／action: 少年が竿を組み立てバケツを置く／reveal: 釣りが始まる直前／hold_back: 水面の異変
2. **上段左・細い横コマ**。左右を開放し、上下は消す。何もない水面と水平線だけ。台詞なし、薄いトーン。
   - purpose: 異変前の静けさを置く／action: 何もない水面を見せる／reveal: まだ事件は起きていない／hold_back: 黒い帯
3. **中段右・細い横コマ**。右辺を残し、左辺を斜めにする。遠くの水面が中間グレーから黒へ変わる。背景なし、黒帯だけ。
   - purpose: 黒い帯を小さく出す／action: 遠くの水面が灰色になる／reveal: 水面が変化し始めた／hold_back: 変化の大きさ
4. **中段左・大きな横断コマ**。上下の間隔を広く取り、左右を開放する。黒い帯がページ幅を横切り、水面の線が一部だけ残る。効果線は粗い筆の一撃を一つだけ。
   - purpose: 異変の面積を増やす／action: 黒い帯がページ幅へ広がる／reveal: 水面の変化は近づいている／hold_back: 何が来たか
5. **下段右・縦長コマ**。右辺・下辺を開放し、上辺を斜めにする。黒い巨大な塊の表面と白い曲線。クジラと断定できる細部は描かない。
   - purpose: 黒い塊を身体として見せる／action: 黒い面と白い曲線が浜へ乗り上げる／reveal: 巨大な生物らしい／hold_back: クジラの顔と全身
6. **最下段・大コマ**。左右・下を開放し、上辺だけ残す。黒い塊の横に少年を小さく置く。少年は竿を持ったまま、黒と白の面積差を最大にする。背景は水面一帯の薄いグレーだけ。
   - purpose: 少年の平静を異変と並べる／action: 少年が黒い塊の横に立つ／reveal: 少年はそれをクジラと認識する／hold_back: クジラの正体
   - dialogue: [{text: クジラだ。まぁ、クジラがいても釣りはできるのか？, speaker: boy, type: thought, reason_to_speak: 異常を釣りの問題へ変換する, reaction_before: 黒い塊を見る, reaction_after: 竿を持ったまま立つ}]

連続性：竿・バケツは1コマ目から6コマ目まで位置を追跡する。黒い波は3コマ目から増え、突然別の物体に置き換えない。白い曲線は7ページのジアの髪へつながるが、6ページでは髪と断定しない。
