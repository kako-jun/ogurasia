# p04「危険な平和」

## 要件

- role: 住民の平静と少年の警戒を対比する
- previous_page: p03
- next_page: p05
- start_state: 少年は食堂を出て海へ戻り、住民は危険を日常会話にしている
- end_state: 少年は危険を理解しても釣りをやめない
- knowledge_delta: ひなげしには殺人事件や危険な水中空間がある
- relationship_delta: 少年は町を観察する側に戻る
- page_turn_reason: 少年が探していた釣り場を見つける
- must_not_explain: 殺人事件を直接描かない。少年の不安を事件の説明にしない
- panel_count: 6
- 完成条件: 恐怖ではなく、少年の考え方の癖として危険を提示する

## ネーム

役割：危険を住民は日常として扱い、少年だけが逃走経路を読む。恐怖の説明ではなく、身体の反応と空間の傾きで示す。

1. **上段右・大きな斜めコマ**。右辺はページ端まで開放、上辺は斜め、左辺と下辺を残す。ひび割れた駐車場を少年が右下へ走る。重心を低くし、片足を浮かせる。背景密度は低〜中、ひびは太い線を数本だけ。
   - purpose: 危険な地面を少年の身体で示す／action: 少年がひび割れた駐車場を走る／reveal: 足元が不安定な町である／hold_back: 走る理由
2. **上段左・小コマ**。上辺・左辺を開放し、住民二人の口元と肩だけを描く。ひび割れの上でも平然と会話する。背景は白、人物の主線を強くする。
   - purpose: 住民と少年の危険認識を対比する／action: 住民二人がひびの上で世間話をする／reveal: 危険が日常会話になっている／hold_back: 少年が何を恐れるか
   - dialogue: [{text: 殺人事件、多いよね, speaker: resident, type: speech, reason_to_speak: 危険を平常の話題にする, reaction_before: ひびを踏む, reaction_after: 平然と歩く}]
3. **中段右・小さな縦コマ**。上下を開放し、右辺だけ残す。少年の視線と、頭の中の逃走経路を点線と矢印で示す。地図は説明図にせず、白地に3本の線だけ。
   - purpose: 少年が逃げ道を読む性格を見せる／action: 少年が出口と水路を頭の中で並べる／reveal: 少年は危険時の経路を考える／hold_back: 逃げる必要があるか
   - dialogue: [{text: 逃げるなら、あっち。でも、あっちは女風呂だった, speaker: boy, type: thought, reason_to_speak: 逃走経路の可笑しさを出す, reaction_before: 出口を見る, reaction_after: 水中入口を見る}]
4. **中段左・縦長コマ**。左辺は消し、右辺を斜めにする。水中の階段・柱・海草を縦に落とす。背景密度は中、海草は細く薄い。少年は出さない。
   - purpose: 風呂と防波堤の境界を曖昧にする／action: 水中の階段と柱を見せる／reveal: 建物の内部が海とつながっている／hold_back: 入口の用途
5. **下段右・大コマ**。右辺・下辺を開放し、上辺を斜め、左辺を残す。風呂にも防波堤にも見える入口を置く。黒い入口と白い余白で曖昧さを作る。吹き出しなし。
   - purpose: 危険を説明せず空間で残す／action: 風呂にも防波堤にも見える入口を置く／reveal: 読者も少年も場所を断定できない／hold_back: 住民の生活の詳細
6. **最下段左・細い余韻コマ**。左・下を開放し、上辺だけ残す。少年が海へ歩き直す。竿は左手に戻り、背中・足・竿の三本の線だけで進行方向を示す。背景なし。
   - purpose: 少年の目的が変わらないことを確認する／action: 少年が竿を持って海へ歩く／reveal: 危険を見ても釣りをやめない／hold_back: 水路に何がいるか

連続性：少年の竿とバケツは1・6コマに残し、途中は画面外と明記する。走る前後で靴、短パン、髪の結びを変えない。ひび割れは背景の主役にしすぎず、少年の足元を読むための補助にする。
