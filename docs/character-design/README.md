# Character design references

おぐらじあ漫画制作の確定キャラクターシート。

- `boy-character-sheet.png`: 匿名性を持つ中性的な少年。顔を一続きの抽象的な髪で隠し、フードなしのシャツと短いズボン。
- `jia-character-sheet.png`: 褐色肌で大きく少し太い、少年より年上のジア。結ばない大きなクジラ風の髪、白い曲線3本、開いた男物のフード付き上着。

画面文法は白・黒・中間トーンの3濃度、線幅1種類。ジアの上着の隙間の中間トーンとズボンは連続させ、ズボン上端の境界線は描かない。

この2枚を第1話のネーム・作画で参照する。候補グリッドや旧版はここへ置かない。
